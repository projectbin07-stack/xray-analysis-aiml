# Contributing

Bug reports, fixes and improvements are welcome.

1. Open an issue first for anything larger than a small fix, so the approach can be agreed.
2. Fork, create a branch from `main`, and keep each pull request focused on one change.
3. Set up the development environment and run the checks described in the README
   (`ruff check .`, `ruff format --check .`, `pytest`). CI runs the same commands.
4. Add or update tests for any behaviour you change.
5. Describe what you changed and how you verified it in the pull request.

Please do not include patient images, personal data, credentials or other private
material in issues, pull requests or test fixtures.
